## 二、B13 因子模型（`quantos_core/factors.py`，1030 行）

### 换掉的问题

| | 样本口径（B7） | 因子口径（B13） |
|---|---|---|
| 参数个数 | `n + n(n-1)/2` | `n·k + k(k+1)/2 + n` |
| 794 只 | **315,615** | **3,980** |
| 自由度比 | 0.006 | 2.43（总量口径） |
| 可解释性 | ρ 是估出来的 | 每个 ρ 拆成「共同因子载荷 + 各自残差」 |

### 四个刻意选择

1. **不用 PCA**：载荷不可解释，符号还会在相邻窗口整体翻转 —— 与 B7 立的
   「σ 从哪来必须能追」直接冲突。改用市场 / 规模 / 动量 / 短期反转四个特征因子。
2. **特征组合口径**：`f_k,t = Σ_i w_ik,t · r_i,t`，w 是 ±3 截断的截面 z 值，
   gross=2、净额=0。与截面回归等价，但不用每天解方程，且每个 f 都能一句话解释。
3. **特征只用 t-1 及之前**（窗口 `[t-w, t-1]`）：与 B12 的「`_settle` 先于
   `_signals`」同一条规矩。
4. **残差逐标的单独估**：不假设同方差。

### 怎么证明它没偷看未来

不靠自觉，靠三段反证（自测 B 段）：

- 改最后一天的收益 → 之前所有天的因子收益**一字不变**，而最后一天确实变了；
- 改第 30 天 → 30 天前不受影响，第 30 天**变了**（t 日收益进 t 日因子）；
- 第 22 天的动量截面里，「昨天暴涨」那只排第一，而它自己在第 21 天暴露还是 0。

再加一条结构保证：前缀和窗口统计与**保留的慢速参考实现逐点对拍**（2,674 个截面值全部一致）。
窗口错一格不会报错，只会让因子收益悄悄错位一天 —— 这种错只能靠对拍抓。

### 一处刻意没给自己开绿灯

`dof_ratio` 在因子口径下是 **2.43**，仍低于门槛 5，结论照旧「仅供参考」。

这个数其实**低估**可用性：载荷是逐标的回归的，每个载荷有 503 个观测，F 的每个参数
有 201 个观测。所以 `describe_model` 把「总量口径」和「逐回归口径」并列打出来，
并明写「本模块不据此自行放行」。

**门槛该由人改，不该由被审的代码自己改。**

### 三条诚实边界

- 等权特征组合，无市值加权、无行业中性化 → 行业效应落进残差（实测残差占比 **74%**）；
- 载荷是窗口内静态回归，不滚动；
- 参数少了≠准了：因子解释不了的共同变动被当成「特质」，相关性被**系统性低估**。

### 真实数据

200 只 × 2,778 天：估出 164 只（36 只因覆盖率 <60% 剔除并记原因），
R² **0.27**、市场因子年化波动 **18.6%**、σ 与样本日波动 ρ=**0.9915**、中位偏差 **-0.2%**。
