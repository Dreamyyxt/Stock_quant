## 现在有什么

四个视图，左侧固定导航（`综合总览 / 预警中心 / 风控与合规 / 运维与审计`），
右上角一排状态：数据新鲜度、时钟、同步、菜单。

- **综合总览**：顶部「今日待处理」栏（5 条，红/橙/黄/蓝按严重度）、5 张 KPI 卡片
  （净值 / 当日收益 / 当前风险敞口 / 当前回撤 / 策略运行）、净值曲线、资金分配、系统健康 6 格。
- **运维与审计**：生产平面健康 7 格、买卖撮合三联快照（账户/策略/挂单）、归因日账
  （六项 + 闭合标记）、风险模型（160 个交易日、年化协方差、自由度、`dof_ratio`）、
  归属预算（strategy × symbol）、三通道探测。
- **风控与合规**：交易权限级别（NORMAL / REDUCE_ONLY / HALTED 三档并列，当前档高亮）、
  三道闸门、端口构成环形图、资金配额与风险贡献、风控阈值配置（可编辑，带来源标注）。
- **策略与审计**：策略生命周期（Research 0 / Backtest 0 / Paper 1 / Live 2）、
  三张策略卡、交易意图汇总（按标的聚合，含敞口占比、置信度、触发依据）。

## 三个诚实缺口（页面如实显示，不是 bug）

1. **净值曲线是空的** —— 文案写「净值序列只有 1 个点（至少需要 2 个交易日的数据）」。
   页面宁可显式说「数据不够」，也不画一条假曲线。
2. **回测还没上屏** —— B12 的回测引擎只跑在命令行
   （`scripts/quantos_backtest.py run/check/compare`），页面里没有回测视图。
   这是 B15（P1）的活儿。
3. **策略生命周期里 Backtest 计数为 0** —— 因为回测结论还没有落成页面可读的产物。

## 一处要看住的红灯

顶部绿条写 `feed · OKX 渠道 degraded · 重连中（第 2/2）`，
右侧「有告警 / 运维令牌 / 刷新」。旁边 `OKX ETH-USDT 订单状态未知` 那条是
「待确认」级别，带「查询并对账」按钮 —— 这类条目**不能点掉就算处理**，
必须走对账确认。页面设计上「标记已知悉」与「查询并对账」是两个不同按钮，就是为了不让人
把「没查」当成「查过了」。
